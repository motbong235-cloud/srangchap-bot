# ស្រង់ឆាប់ (SrangChap)

Telegram bot ទាញ **video / រូប / audio** ពី:

- TikTok
- Facebook / FB Reels
- Instagram
- YouTube / Shorts
- X (Twitter)
- និង site ដែល yt-dlp គាំទ្រ

## ប្រើប្រាស់
1. ផ្ញើ link មក bot
2. រង់ចាំ bot ទាញ និងផ្ញើ file ត្រលប់

## Render
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- Env: `BOT_TOKEN`, `ADMIN_ID`, `DATA_DIR=/var/data`
- Disk: `/var/data` (temp downloads)

## ច្បាប់
ប្រើសម្រាប់ content ដែលអ្នកមានសិទ្ធិ / public។ គោរព ToS របស់ platform នីមួយៗ។
